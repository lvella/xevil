# XEvil

XEvil is a 3rd person, side-view, fast-action, kill-them-before-they-kill-you game. Fight against either computer-controlled enemies, or another player.

You sinned in life. And now you must pay. Satan pits the recently deceased against each other to fight for rank in Hell. Your skill determines your fate for all eternity. This contest is known as XEvil.

## About this fork

This is a maintenance fork of XEvil 2.02, the latest version of XEvil published by Steve Hardt at https://www.xevil.com.

The changes are minimal so it would compile with modern compilers. To build it on Linux, run:
```
HOSTTYPE=x86_64 make 
```

## Other forks

For a more active fork of the game, with new content and modern UI,
please check XEvil 2.5 at https://github.com/kaylaream98/xevil
